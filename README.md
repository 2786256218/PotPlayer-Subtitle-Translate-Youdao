# PotPlayer网易有道字幕翻译插件

本项目旨在通过调用有道api实现字幕翻译的插件，它是在线的，使用前请保持良好的网络

使用后

![after](https://github.com/user-attachments/assets/a2b15b34-eee0-41b7-83df-98ca177289ac)

##安装前的准备

1.首先注册有道智云账户(https://ai.youdao.com/login.s)

![image](https://github.com/user-attachments/assets/e69e56ae-cbba-44cc-b7c3-94bd82ffbe43)


2.之后来到控制台(https://ai.youdao.com/console/#/)

找到自然语言翻译服务->文本翻译点击创建应用

![image](https://github.com/user-attachments/assets/e2c819ca-cf0a-49cc-9df6-f8e8feb6df35)

3.自定义名称并填写相关信息

通常情况下仅勾选文本翻译服务即可，如果你需要其他业务也可以自行选择进行勾选

接入方式必须选择为API!!!

类别随意填写

![image](https://github.com/user-attachments/assets/6135c2eb-bb71-42b9-94ed-b08f568ebd65)

确定创建后如下图，多出来一个刚创建的应用

![image](https://github.com/user-attachments/assets/b52dfbbf-be4a-445c-ad7a-b664d4f9b3b6)

复制你的应用ID和应用密钥来进行接下来的安装操作

## 安装

1.下载安装PotPlayer播放器进入到根目录之后找到Extention\Subtitle\Translate目录

2.将SubtitleTranslate - Youdao.ico和SubtitleTranslate - Youdao.as文件直接复制进去即可

3.打开PotPlayer右键任意位置

![image](https://github.com/user-attachments/assets/68f4c870-b970-4607-91c2-1aae1a9227cb)

4.点击选项并找到拓展功能->实时字幕翻译

![image](https://github.com/user-attachments/assets/6530fa42-29be-448f-aceb-954dcfb72751)

5.选中Youdao translate后点击账户设置

6.填写前面注册到的有道api信息

![image](https://github.com/user-attachments/assets/5f66bc5e-e42e-4a4b-bd4b-daf10567438b)

如果api验证通过

![image](https://github.com/user-attachments/assets/d38c4e6a-8c85-4b35-b062-818b31b45a2b)

7.将翻译引擎选择为Youdao translate即可，其余的选项根据自己的需求选择

8.应用配置完成安装
